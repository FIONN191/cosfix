# CosFix 场照诊断

cos 场照修图方向建议器。上传一张场照（未修原片或已修成品），诊断问题与改进方向，生成可直接粘贴到 AI 修图工具的提示词。可选上传参考图，得到「你这张离目标还差什么」的逐项分析和靠拢路线图。

> **状态：设计阶段，尚未实现。** 完整设计见 [docs/superpowers/specs/2026-07-27-cosfix-design.md](docs/superpowers/specs/2026-07-27-cosfix-design.md)。

## 打算做成什么

**输入**：主图 + 状态开关（原片／已修成品）+ 可选参考图 + 可选备注（角色名、想要的感觉）。

**本地先算指标**：上传后在浏览器里算完直方图、高光暗部裁切、白平衡偏移、肤色判定、锐度、噪点、主色板、构图重心、EXIF，把数值连同图片一起喂给视觉模型。诊断有数据支撑，不是空口感觉。

**八维度诊断**：影调曝光、色彩白平衡、肤色、光影、构图裁切、质感细节、**cos 专属**（假发边缘、美瞳反光、妆面还原、服装材质穿帮、道具塑料感、背景现代元素穿帮、角色氛围契合度）、后期痕迹。

每条问题标注严重度、位置、成因，以及**可解决性**——`后期可修` / `需 AI 生成` / `拍摄决定·修不回来`。最后这档是底线：修不回来的就明说，不生成假建议。

**提示词产出**：针对 Gemini / Nano Banana、即梦 / Seedream / 可灵、Flux Kontext、ChatGPT 四家分别适配写法，每个问题给轻／中／重三档强度，自动附带「保护清单」（发色发型、瞳色、服装纹样、特定道具），防止 AI 顺手改掉角色特征。

## 形态

单个 Vite + React 工程，同一份产物跑两个壳：

- **桌面版**：Electron，Mac DMG / Win EXE，AI 调用走主进程无 CORS 限制，key 加密存本地
- **网页版**：Vercel + Serverless Function 转发

支持 Claude、OpenAI、Gemini、豆包、智谱、通义、OpenRouter，key 自备。
